سكينة - موقع (PWA)

الملفات:
index.html            التطبيق كاملًا (المصحف + الأذكار + المواقيت + القبلة + الإعدادات)
admin.html            لوحة الإدارة (تجهّز config.json)
config.json           إعدادات المحتوى: رسالة للمستخدمين + أذكار مضافة + إخفاء أقسام
manifest.webmanifest  بيانات التثبيت كتطبيق
sw.js                 للعمل بدون إنترنت
icon-192.png / icon-512.png  الأيقونات

الرفع المجاني من الهاتف (GitHub Pages):
1) أنشئ حسابًا على github.com ثم New repository باسم sakinah (Public).
2) اختر Add file > Upload files وارفع كل الملفات (من Chrome فعّل "نسخة سطح المكتب" إن لزم) ثم Commit.
3) Settings > Pages > Source: Deploy from a branch > main / (root) > Save.
4) بعد دقيقة يصبح الموقع على: https://اسم-حسابك.github.io/sakinah/

بعد الرفع:
- أندرويد: افتحه في Chrome ثم القائمة > تثبيت التطبيق.
- آيفون: افتحه في Safari ثم مشاركة > إضافة إلى الشاشة الرئيسية.
- البوصلة تحتاج HTTPS وهو متوفر تلقائيًا في GitHub Pages.

الإدارة:
افتح /admin.html عدّل ثم نزّل config.json وارفعه فوق القديم في المستودع (Add file > Upload files).

- بعد رفع التحديث افتح الموقع وأعد تحميله مرتين حتى يتحدث الكاش (sakinah-v2).

تحديث 3: صارت التلاوات في تبويب مستقل (التلاوات)، والمصحف للقراءة فقط. تتابع السور تلقائيًا، مع خيار تناوب القرّاء. افتح الموقع وأعد تحميله مرتين بعد الرفع.

تحديث 4 (دون إنترنت): بعد أول زيارة بالإنترنت يعمل الموقع كله دون اتصال (المصحف والأذكار والقبلة والمواقيت بالحساب المحلي). لتلاوة دون إنترنت: من تبويب التلاوات اضغط «تنزيل» بجانب السورة. الصوت المنزَّل يُحفظ على الجهاز.

تحديث 5 (الأذان): ضع ملف أذان باسم adhan.mp3 بجوار index.html، أو اخترْه من الإعدادات > الأذان. يعمل وقت الصلاة والتطبيق مفتوح (المواقيت من Aladhan API). فعّل «تنبيهات الصلاة» من الإعدادات.

تحديث 6: الأذان تلقائي بالكامل ويتحكم فيه المشرف فقط من admin.html (تشغيل/إيقاف، ملف الأذان وأذان الفجر، كتم أي صلاة، إبقاء الشاشة). ارفع config.json بعد التعديل. ملف الأذان adhan.mp3 يوضع بجوار index.html.

تحديث 7 (تسجيل الدخول + جودة الصوت):
- تسجيل الدخول عبر Supabase (اختياري، والتطبيق يعمل كاملًا بدونه): الإعدادات > الحساب. يزامن العلامات وموضع القراءة وعدّاد الأذكار والإعدادات بين الأجهزة.
- الإعداد: (1) أنشئ مشروعًا على supabase.com (2) SQL Editor: شغّل supabase.sql (3) Project Settings > API: انسخ Project URL والمفتاح العام (anon/publishable) إلى supabase-config.js (4) Authentication > URL Configuration: ضع رابط موقعك على GitHub Pages في Site URL وفي Redirect URLs (لروابط التأكيد واستعادة كلمة المرور).
- المصحف (النص) داخل index.html ويعمل دون إنترنت بعد أول زيارة. الصوت: اختر جودة (عادية/عالية) من تبويب التلاوات ثم نزّل السور وأنت متصل. التنزيل يُحفظ لكل قارئ وكل جودة.
- افتح الموقع وأعد تحميله مرتين بعد الرفع (الكاش صار sakinah-v7).
